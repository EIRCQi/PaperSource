你的本地文献工作台

点击“导入 PDF”选择文献，或导入整个文件夹。也可以拖放 PDF 文件到窗口。文件会复制到文献库，原文件保持不变。

相同内容的 PDF 自动去重。重复文献若已在回收站，请先恢复。点击列表卡片编辑题录、标签、状态和笔记；修改后点击“保存修改”。

勾选文献左侧复选框后点击“批量整理”，支持状态、星标、标签和回收站操作。每批最多 500 篇，可以跨页选择；切换筛选或刷新列表会清空选择。有未保存编辑时请先保存。

搜索覆盖题录、标签和笔记，暂不支持 PDF 正文搜索、OCR 或自动识别作者。标题默认使用文件名。

快捷键：⌘S / Ctrl+S 保存，⌘K / Ctrl+K 搜索。批量导入可点击“停止导入”，当前文件完成后停止。

草稿暂存在当前标签页，刷新后再次选中文献可恢复；关闭标签页可能丢失草稿，请及时保存。遇到版本冲突，先复制需要保留的内容，再点击“重新载入”合并修改。

完整备份与恢复

点击“完整备份”生成包含 PDF、题录、笔记和回收站记录的快照，完成后显示备份位置。请把备份文件夹复制到外部磁盘，以防本机磁盘损坏。恢复命令见 README，恢复只创建新目录。也可退出程序后手动复制整个数据目录。

JSON 导出包含题录和笔记；BibTeX 导出不含笔记，均不能代替完整备份。回收站只隐藏文献，不删除 PDF。
