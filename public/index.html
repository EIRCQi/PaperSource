批量识别题录

每次最多 100 篇。只补全空字段；标题仍是文件名时可替换。已有作者、关键词等不会覆盖，笔记与标签保留。识别后请逐项核对再保存。

识别题录

自动分类

根据标题、文件名、期刊和已提取的论文关键词匹配，可添加多个分类，不替换原有标签。不会分析全文或删除文件。

提供 32 类中英文关键词规则，可按学科补充；保留已有同名规则。修改后请预览并保存，最多 40 条。

彻底清除文献

将删除文献库中的 PDF 副本、题录和笔记，无法从回收站恢复。原始导入文件和已有备份不会删除。

批量整理文献

只修改选中的文献；有版本冲突时整批不修改。

导出书目

导出已保存的内容；当前筛选不会限制导出范围。

这两种文件都不含 PDF。迁移或备份全部数据请使用“完整备份”。

你的本地文献工作台

点击“导入 PDF”选择文献，或导入整个文件夹。也可以拖放 PDF 文件到窗口。文件会复制到文献库，原文件保持不变。

相同内容的 PDF 自动去重。重复文献若已在回收站，请先恢复。点击列表卡片直接阅读 PDF、记录笔记；上方“宽屏阅读”可放大工作区，大屏下 PDF 与笔记左右并排。切换“题录整理”可编辑标题、标签与阅读状态；修改后点击上方“保存修改”。详情顶部“删除（移入回收站）”可删除单篇，列表“删除所选”可批量删除。在回收站选中文献，详情顶部可“彻底删除此篇”；回收站列表也可删除所选或清空全部。

勾选文献左侧复选框后点击“批量整理”，支持状态、星标、标签和回收站操作。每批最多 500 篇，可以跨页选择；切换筛选或刷新列表会清空选择。有未保存编辑时请先保存。

左侧“未分类”“资料待补全”“有分类建议”自动筛选待整理文献。顶部“自动分类”可编辑关键词规则、预览并确认标签；已有规则可用“补充预设分类”追加更多学科；默认对新导入文献自动打标签，可在该窗口关闭。

导入时会从 PDF 内嵌题录和前两页文字识别标题、作者、关键词、DOI 等；请核对识别结果。已有文献可在“题录整理”中点击“识别题录”，勾选候选字段填入后保存。也可在列表勾选最多 100 篇，点击“批量识别题录”，开始识别并核对后统一保存。批量只补空字段及文件名标题；可停止识别，已有笔记和标签保留。搜索覆盖题录、关键词、标签和笔记，暂不支持 PDF 全文搜索或 OCR。

快捷键：⌘S / Ctrl+S 保存，⌘K / Ctrl+K 搜索。批量导入可点击“停止导入”，当前文件完成后停止。

草稿暂存在当前标签页，刷新后再次选中文献可恢复；关闭标签页可能丢失草稿，请及时保存。遇到版本冲突，先复制需要保留的内容，再点击“重新载入”合并修改。

完整备份与恢复

点击“完整备份”生成包含 PDF、题录、笔记和回收站记录的快照，完成后显示备份位置。请把备份文件夹复制到外部磁盘，以防本机磁盘损坏。恢复命令见 README，恢复只创建新目录。也可退出程序后手动复制整个数据目录。

JSON 导出包含题录和笔记；BibTeX 导出不含笔记，均不能代替完整备份。移入回收站仍可恢复；“彻底删除”会清除库内 PDF 副本和记录，无法从回收站恢复。
