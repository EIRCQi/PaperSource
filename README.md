# 文栖 PaperDesk 0.3.0

中文本地文献管理器。无需登录、无需 npm install、无需联网服务。需要已安装 Node.js 20 或更高版本；数据仅保存在运行程序的电脑。支持 macOS、Windows、Linux，使用系统浏览器界面。

## 0.3.0 更新

- 新增“完整备份”：在本机生成 PDF、题录、笔记和回收站记录的快照；逐份校验 PDF 大小和 SHA-256 内容哈希。
- 新增 `npm run restore`：从完整备份恢复到一个新目录，原文献库保持不变；损坏备份拒绝恢复。
- 新增 BibTeX 导出：导出全部有效文献或详情中的单篇文献；不导出笔记和回收站记录。
- 启动时检查书目结构，对损坏数据给出恢复提示；区分运行锁与目录权限错误。

## 0.2.0 更新

- 保存时检查文献版本，防止多标签页互相覆盖；冲突时保留当前编辑内容。
- 本标签页自动暂存草稿，刷新后再次选中文献可恢复。草稿使用浏览器会话存储，不等于正式保存；关闭标签页、清理浏览器数据或更换启动端口可能无法恢复。重要笔记仍请点击保存。
- 文献列表每页 50 篇，搜索支持空格分隔多个关键词，同时匹配题录、标签与笔记；兼容全角输入。标签数量一次统计，减少重复扫描。
- 批量导入可以停止：当前文件完成后停止后续文件，显示新增、重复、失败、未处理数量；已导入文件保留。
- 支持 `⌘S / Ctrl+S` 保存、`⌘K / Ctrl+K` 聚焦搜索；小屏幕也能选择标签。
- PDF 支持后缀范围请求和 HEAD 请求；笔记首尾换行与缩进保持原样。

### 从 0.1.0 / 0.2.0 升级

先停止旧程序并备份整个 `PaperDeskData`。替换源码或在克隆的仓库中执行 `git pull`，再运行 `npm run open`，刷新已有浏览器页面。无需安装依赖或迁移文献库。

如果出现版本冲突，先复制想保留的编辑内容，点击“重新载入”，然后在最新版本中合并并保存。重新载入会在确认后放弃本页未保存的修改。旧页面没有版本信息时会拒绝保存，刷新即可使用新版。

## Mac 启动

解压软件包。打开终端输入 `cd `（注意空格），把解压后的项目文件夹（例如 `PaperSource-main`）拖进终端，按回车，然后运行：

```bash
npm run open
```

也可以双击 `Start.command`。如果系统不允许双击运行，请使用上面的终端启动方式。Windows 可双击 `Start.bat`；Linux 使用 `npm run open`。

启动后浏览器自动打开。默认地址 http://127.0.0.1:4321，端口被占用时自动选择空闲端口，以终端打印地址为准。使用时保留终端窗口，按 Control+C 退出。关闭浏览器标签页不会停止程序。

## 使用

1. 选择“导入 PDF”，支持多选；“导入文件夹”递归导入选中文件夹里的 PDF。拖放支持 PDF 文件，不支持直接拖放文件夹。
2. 单个文件最大 50 MB，逐个上传，不会移动或改写原文件。内容完全相同的 PDF 只保留一份。
3. 选择文献，填写标题、作者、年份、期刊和 DOI，用中文或英文逗号分隔标签。
4. 设置待阅读、阅读中或已读完，勾选星标，记录笔记，然后点击“保存修改”。未保存内容在切换文献或关闭窗口时会提示。
5. 打开 PDF 新标签页阅读，或展开内嵌预览。显示能力取决于浏览器内置 PDF 阅读器。
6. 搜索覆盖标题、作者、年份、DOI、期刊、标签、笔记。搜索不包含 PDF 正文。回收站中的文献仅在回收站搜索中显示。
7. 移入回收站后可恢复，第一版不提供彻底删除。重复导入回收站内的文献时，请先在回收站恢复。

## 数据与备份

默认目录：用户主目录下 `PaperDeskData`，Mac 通常是 `/Users/你的用户名/PaperDeskData`。界面“使用与备份说明”展示实际位置。

- `catalog.json`：全部题录、笔记和分类；原子替换写入。
- `catalog.json.bak`：上一次成功修改前的题录快照，并不是完整历史备份。
- `files/`：按内容哈希命名的 PDF 副本。
- `running.lock`：防止多个程序同时写入同一文献库的运行锁，正常退出自动删除。

**完整备份**：先 Control+C 退出程序，再复制整个 `PaperDeskData` 文件夹到备份磁盘。**恢复**：先关闭程序，用备份替换该目录，再重新启动。可以先将现有目录改名保留，避免覆盖后无法撤回。

### 一键完整备份

点击顶部“完整备份”。程序把**点击时已保存的内容**复制到数据目录下的 `backups/backup-...` 文件夹，备份完成后界面显示具体路径、文献数量和 PDF 总大小。备份期间仍可编辑；稍后的修改属于下一份备份。

备份包含 `catalog.json`、`files/` 和带校验信息的 `manifest.json`。文件缺失或损坏时，备份失败并清理未完成副本；原库不变。备份需要接近当前 PDF 总大小的可用磁盘空间。备份与原库位于同一磁盘，**请将完成的备份文件夹复制到外部磁盘**。备份不会复制历史备份文件夹，也不会自动删除旧备份。

### 从完整备份恢复

在项目目录中运行，路径请替换为自己的实际路径：

```bash
npm run restore -- "/备份位置/backup-..." "/Users/你的用户名/PaperDeskRestored"
```

新文献库目录必须不存在，其父目录必须已存在；省略第二个参数时，程序在用户主目录自动创建一个新的 `PaperDeskRestored-...` 目录。题录和 PDF 的校验全部通过才算恢复成功。源备份和原文献库都不会被覆盖。

在 macOS / Linux 上，用恢复后的目录启动：

```bash
PAPERDESK_DATA="/Users/你的用户名/PaperDeskRestored" npm run open
```

Windows PowerShell 中：

```powershell
$env:PAPERDESK_DATA="C:\Users\你的用户名\PaperDeskRestored"
npm run open
```

每次启动恢复库都要指定此目录。确认恢复内容正常后，也可停止全部文栖进程，保留原库副本，再手动将恢复目录移到默认 `PaperDeskData` 位置。

### 书目导出

“导出书目”提供两个选项，均导出已保存内容，且不受当前搜索或标签筛选限制：

- JSON：全部题录及笔记，含回收站记录，不含 PDF。本版不提供书目 JSON 导入；它不是完整备份格式。
- BibTeX：全部有效文献，不含回收站或笔记；文献详情也可导出单篇。作者使用中文或英文分号分隔后，会转为 BibTeX 的作者列表。尚无文献类型字段，因此条目统一用 `@misc`，需要时在引用软件里补充类型。

BibTeX 文件使用 UTF-8，保留中文。LaTeX 工程处理中文的能力取决于所用工具链；程序将输入按普通文本转义，不将元数据解释为 LaTeX 命令。格式参考：[BibTeX 格式](https://www.bibtex.org/Format/)与[特殊字符](https://www.bibtex.org/SpecialSymbols/)。

可用环境变量 `PAPERDESK_DATA` 指定其他数据目录（不要同时让多个设备写入同步盘目录），用 `PORT` 指定首选端口。

## 异常处理

- 提示“数据目录已锁定”：先检查另一终端中是否已经运行文栖。若曾强制关机或强制结束进程，确认所有文栖进程均已停止后，再删除数据目录内的 `running.lock`。
- 数据库损坏时程序停止并报告错误，不会自动覆盖。关闭程序并备份整个目录后，可检查 `catalog.json.bak` 或从完整备份恢复。
- 提示保存失败：保留页面中的笔记，检查磁盘剩余空间及数据目录写入权限，再重试保存。
- 浏览器打不开 PDF：使用“打开 PDF”，检查浏览器 PDF 阅读设置。

## 范围

这是可运行的首版本地应用，尚非签名安装包。未实现自动提取题录、PDF 全文搜索、OCR、DOI 联网检索、BibTeX 导入、RIS、云同步或 PDF 标注。标题先使用文件名，其他题录手工补充。适合个人中小规模文献库，超大规模性能尚未验证。

服务仅绑定本机 127.0.0.1，校验 Host、Origin 和会话令牌。不包含遥测或远程 API。界面不提供账号系统，不用于共享电脑上的用户隔离。应用无第三方运行依赖。
